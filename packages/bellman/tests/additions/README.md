# The additions of the case studies

The files of the sixteen pre-implementation case studies of specification 0.7 that the package's tests read and that no application holds: each case study's refusals file `refusals.bl`; the stage files, additions and trellis files of the two new applications under `new-applications/`; and the two files of consumption-savings-iid, `methods.bl` and `methods.additions.bl`, whose union the application holds as its one addition. The methods files of the fourteen case studies that are applications stand beside their stage files, `applications/<model>/declaration/stages/<key>/methods.bl`, where the tests read them. `expected.json`, written by the specification's tool, records for each run the stage file, the additions, the count of places the elaborated union gives and the names the additions created.
