# The tests' scripts

Two oracles of the package's standing rules, placed with the tests because the tests run them, and two modules of the structural tests of the applications. The oracles change no file. Run each from the repository root with `./venv/bin/python` and `PYTHONDONTWRITEBYTECODE=1`. This folder is not a package: a test runs a script by its path, and a structural test of an application places the folder on its path to import the two modules.

`local_imports.py` measures the placing of imports in `packages/bellman/bellman/` and the cycles of the import graph among the package's own modules. `./venv/bin/python packages/bellman/tests/tools/local_imports.py` prints, for each module, the count of imports inside functions or classes, the count at module level, and the total, then the cycles as lists of module names, with `bellman/__init__.py` excluded from the graph. It then prints each import of a module in one of the eleven folders that reads a later folder, the package root or a module at the root other than `bellman/refusals.py`, reading the order of the folders from the table of the folders in `packages/bellman/README.md` (§3); it refuses to run, saying why, when that README has no heading of the folders or its table leaves out a folder of the package. It also reads the export table `_EXPORTS` of `bellman.stage`, `bellman.period` and `bellman.trellis`, the package's three namespaces, and prints each entry that names no module of the package, no defined name, or a name two tables map to different modules. With `--strict` a nested import, a cycle, an import against that order or a table entry without its definition is an exit status 1. Each module imports at its head from its own folder, the folders before it and `bellman/refusals.py`, so the nested count is zero, the graph has no cycle and no import reads against the order. `--package` names one of the folders, `bellman.stage` for instance, to measure that folder alone.

`identity_parse_sites.py` measures the remaining sites that take an identity apart, the sites that assemble one outside `identity.py`, and the sites that split a name at a dot. `./venv/bin/python packages/bellman/tests/tools/identity_parse_sites.py` reads `packages/bellman/bellman/` and the tests beside it, this folder excepted, lists every line that contains `split(":")`, `rsplit(":")`, `partition(":")`, `endswith(":` or `replace(":`, or one of the shapes its docstring names, then the counts per module and the totals, and the exemptions with their reasons. With `--strict` a non-zero total is an exit status 1. AMD-SG-016 rules that an identity is a frozen record constructed in one place, so that the totals are zero, and AAS kept that count on 27 September 2026.

`stage_ast.py` holds the helpers of the structural tests under `applications/`: the parsed term of a stage file, the spellings in which those tests write their expected terms, `check`, which names the first place where a parsed term and an expected one differ, and the printers of a term in ASDL notation and in HTML.

`stage_types.py` re-exports the term classes of `bellman.syntax.terms` under the module name those tests import.
