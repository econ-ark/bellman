## The command

With Node 22 and npm, run `bash build.sh` from this folder. The script installs the lockfile with `npm ci`, builds one immediately invoked script with Rollup, writes the notices, and copies the seven files to `../../bellman_workbench/public/flow/`. Set `npm_config_cache` to choose a cache folder. Registry access is needed unless the cache holds the packages. `dist/` and `node_modules/` are not tracked.

Rollup reports three known upstream warnings: React Flow's `use client` directive is ignored in this browser bundle, d3-selection has circular imports, and the unchanged layout script's top-level `this` is rewritten to `undefined`. The layout script uses `self` in a browser. The recorded loading probe passed. The recipe does not suppress these or other warnings.
