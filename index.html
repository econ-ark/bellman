Project Bellman is the world's first truly declarative, AI-integrated development environment for economists. It lets you build rich, dynamic heterogeneous agent models using reusable stages, focusing on economic relationships, not numerical details. Maps directly from paper to model.

Start with an example GitHub (opens in a new tab)

!Properties

Expressive
Any stochastic decision process can be written in the language, not only the cases a toolkit anticipated.
Modular
Stages written separately compose into whole models. Models grow by adding stages, not by rewriting.
Declarative
The specification states the economics. Solution methods are chosen separately and can be exchanged.
