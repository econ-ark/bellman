# Editor support

`dynspec-vscode/` is the extension of VS Code and Cursor for stage files (`.bl`): highlighting, with each declared name colored by its role, the input of mathematical italic letters and set glyphs, and the folding of block headers. Its [README](dynspec-vscode/README.md) gives the two ways to install it, a symbolic link from the repository or a packaged file, and the rules of its input.
