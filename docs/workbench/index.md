# Bellman Workbench

Use Workbench to write a Bellman-SYM model and inspect the economic problem described by its files. Select an equation or a box in the diagram to see how the two correspond. Open a recipe to see how stages are linked across decisions and periods, and which parameter values and methods the model uses.

| If you want to | Start here |
|---|---|
| Open the supplied portfolio model and trace a decision to its equation | [Quickstart](00-quickstart.md) |
| Open a folder, navigate the editor, or save a file | [Open and edit a project](02-open-and-edit.md) |
| Read a stage, follow a connection, or understand a diagnostic | [Inspect a model](03-inspect-a-model.md) |
| Change an equation, parameter, setting, or method | [Edit equations and inputs](04-edit-equations.md) |
| Build a model from stages and connect their fields | [Create and connect stages](05-create-and-connect.md) |

| Ask a question or build a draft from an economic description | [Build a model with Matsya](01-matsya.md) |
| Keep changes in Git, export a diagram, or diagnose a problem | [Share a project and get help](07-share-and-troubleshoot.md) |

The browser and desktop versions use the same editor and model diagrams. See [Install Bellman Workbench](../overview/00-install.md) for setup. For the sequence from a declaration to a numerical solution, see the [modelling workflow](../overview/06-workflow.md).
