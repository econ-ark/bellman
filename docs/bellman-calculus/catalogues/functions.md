# Appendix E.2 — Function types

> [!summary]
> Functions have argument and result domains, including functions defined locally inside an equation. This catalogue lists the value functions, transitions, aggregators, and policies associated with a stage. Operators acting on those functions also have domain and codomain types.

> [!info]- Relationship with other documents
> **Builds on** — [Fields, functions and types](../04-fields,%20functions%20and%20types.md) distinguishes fields from their representatives.
> **Used by** — Bellman-SYM's [Appendix C](../../Bellman-Sym/appendices/14-appendix-c-syntax-to-semantics.md) and [Appendix D](../../Bellman-Sym/appendices/15-appendix-d-node-tag-and-field-indexing.md) state the representation and substitution rules for these functions.
> **See also** — [Field types](./fields.md) lists value domains and information contexts.
> **See also** — [Operators](./operators.md) lists operations on these function spaces.

A **function type** specifies a domain and codomain. We write $\operatorname{Meas}(A,B)$ for measurable maps from $A$ to $B$. A representing function is distinct from the field obtained by evaluating it at a random state. Representation up to almost-sure equality requires a version of the field measurable with respect to the information generated by the state, together with suitable measurable value domains. A version is a random variable agreeing with the field almost surely. Sufficiency for the model's conditional laws and payoffs is a separate requirement; see Bellman-SYM's Appendix C, §1.2 and rule R5.

## 1. Functions of a stage

For perch $p\in\{\prec,\sim,\succ\}$, let $\mathsf X_p$ be its state space and $\mathsf L$ the value domain. The action domain is $\mathsf A$, feasible actions are $\Gamma(x)$, and $\operatorname{Gr}(\Gamma)=\{(x,a):a\in\Gamma(x)\}$ is the feasible state–action domain. Shock spaces are $\mathsf Z_\zeta$ before choice and $\mathsf Z_\eta$ after choice.

| Function | Domain and codomain | Interpretation |
|---|---|---|
| $\mathrm v_\prec,\mathrm v,\mathrm v_\succ$ | $\mathsf X_p\to\mathsf L$, in a specified function space $\mathsf V_p$ | supplied or derived value representatives |
| $\partial_j\mathrm v_p$ | $\mathsf X_p\to\mathbb R$ where defined | derivative with respect to state coordinate $j$, when the function is differentiable |
| $\mathrm g_\prec$ | $\mathsf X_\prec\times\mathsf Z_\zeta\to\mathsf X_\sim$ | arrival-to-decision transition |
| $\mathrm g_\succ$ | $\operatorname{Gr}(\Gamma)\times\mathsf Z_\eta\to\mathsf X_\succ$ | decision-to-continuation transition |
| $\mathrm G_\succ$ | $\mathsf L\times\operatorname{Gr}(\Gamma)\times\mathsf Z_\eta\to\mathsf L$ | pointwise decision reward/continuation aggregator, where defined |
| $\mathrm G_\prec$ | $\mathsf L\times\mathsf X_\prec\times\mathsf Z_\zeta\to\mathsf L$ | pointwise arrival aggregator, identity in the buffer-stock example |
| $\pi$ | $\mathsf X_\sim\to\mathsf A$ | measurable feasible policy, $\pi(x)\in\Gamma(x)$ |
| $Q_f$ | $\operatorname{Gr}(\Gamma)\to\mathsf L$ | choice value for a specified continuation function $f$ |
| $\mathrm u$ | $\mathbb R_{++}\to\mathbb R$ in the consumption example | typed utility function, including when defined locally |

Measurability, integrability, and closure under the required operators restrict the listed function spaces. A derivative line states the author's assertion about the derivative of the value its builder writes; it is not a differentiability theorem. A policy derived from a solution relation requires existence and a specified measurable selection; optimality is an additional condition.

## 2. Local functions and distribution pairing

A declared function retains its typed parameters and result domain when substituted into another expression. Its local parameter names are distinct from stage fields with the same spelling. The derivative operator on a declared function, `D_{c}(𝑢)`, the derivative term on a value field, `D_{a}V[>]`, and the function name `𝑑𝑢` therefore remain distinct. Bellman-SYM's Appendix D, §§4–5, gives the substitution rules.

Probability measures $\mu_p\in\mathsf M_p$ are separately defined objects on $\mathsf X_p$. Their pairing with an integrable function is $\langle\mu_p,f\rangle=\int f\,\mathrm d\mu_p$. The forward transition on measures pairs with the undiscounted transition expectation on functions, as defined in [Stages and perches](../03-Stages%20and%20perches.md) §2.7. This does not identify a measure with a value function or make the reward-bearing Bellman operator its transpose.
