# Housing investment with adjustment frictions

A household holds financial assets and a house; each period it chooses whether to adjust the house and then its consumption, the adjuster choosing the new house at a cost proportional to its value (Dobrescu and Shanker 2024, Application 2).

The command `bellman-workbench applications/housing-frictions` opens the model in the Workbench.

A program run on this model writes its output into `results/`, which git ignores.
