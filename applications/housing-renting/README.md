# The housing model with renting and a capital income tax

Each year a household chooses whether to own or to rent, then the size of the house or the quantity of housing services, and then its consumption, under a tax on capital income (Dobrescu and Shanker, "A fast upper envelope scan method for discrete-continuous dynamic programming", SSRN Working Paper No. 4181302, Application 3).

The command `bellman-workbench applications/housing-renting` opens the model in the Workbench.

A program run on this model writes its output into `results/`, which git ignores.
