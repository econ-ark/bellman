# Pensions and housing over the life cycle in Australia

A worker enrolled in a sector pension plan chooses each year a voluntary contribution rate and a risky share for the pension balance, and whether to rent, to keep the house owned or to change it, with consumption and a mortgage; at 65 the pension is paid out, and the wealth left at death is bequeathed (Dobrescu, Shanker, Bateman, Newell and Thorp 2023).

The command `bellman-workbench applications/pensions-australia` opens the model in the Workbench.

A program run on this model writes its output into `results/`, which git ignores.
