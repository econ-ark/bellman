# The durables model: keeping or adjusting a housing stock

A household holds financial assets and a house; each period it chooses between keeping the house and selling it to buy another, and then chooses its consumption, the adjuster also choosing the new house.

The command `bellman-workbench applications/durables` opens the model in the Workbench.

A program run on this model writes its output into `results/`, which git ignores.
