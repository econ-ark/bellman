This folder is a Matsya project: its model, described in `economics.md` and declared in `declaration/`, is written and checked by the Matsya service through the command `bellman-matsya`, and the folder's session on the service keeps the model's text, its jobs and their questions. Before you work on the model, read `.bellman-matsya/README.md`, which names the session and the commands used most, and run `bellman-matsya docs --all`, which prints the whole user guide of the command. Project, job, session, ask, index and search commands accept `--json` for structured answers.
