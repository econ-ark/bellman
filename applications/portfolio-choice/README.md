# The portfolio-consumption model

This folder is superseded by [`applications/cons-port/`](../cons-port/README.md), which holds the model's stages written the method way, and is marked for deletion (AAS, 28 October 2026); the readers to repoint before the deletion are counted in the issue that marks it.

A household consumes out of its resources and divides its savings between a safe asset and a risky one, choosing the share before the risky return and next year's income are drawn.

The command `bellman-workbench applications/portfolio-choice` opens the model in the Workbench.

A program run on this model writes its output into `results/`, which git ignores.
