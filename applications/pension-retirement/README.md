# Savings and retirement choice with pension assets

A worker with financial and pension assets consumes, contributes to the pension and chooses whether to work next period, and a retiree receives the pension balance as a lump sum and a benefit each period (Dobrescu and Shanker 2024, Application 1).

The command `bellman-workbench applications/pension-retirement` opens the model in the Workbench.

A program run on this model writes its output into `results/`, which git ignores.
