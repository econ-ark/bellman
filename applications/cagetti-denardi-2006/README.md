# Entrepreneurship, frictions and wealth: the model of Cagetti and De Nardi (2006)

Young households choose between working and running a business, old entrepreneurs between staying in business and retiring, entrepreneurs borrow against a limit that the threat of default sets, and a dying household leaves its assets to an offspring whom it values.

The command `bellman-workbench applications/cagetti-denardi-2006` opens the model in the Workbench.

A program run on this model writes its output into `results/`, which git ignores.
