# The housing model of an owner

An owner chooses its housing stock, at a proportional transaction cost when it moves, and then its consumption out of the cash on hand that remains, its income following a discrete Markov law.

The command `bellman-workbench applications/housing-owner` opens the model in the Workbench.

A program run on this model writes its output into `results/`, which git ignores.
